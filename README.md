# NOIR TABLE — Dark Food Portfolio

เว็บไซต์ตัวอย่างแนว Dark UI ที่ผสมผสานหน้าแนะนำตัวกับแกลเลอรีเมนูอาหาร ตามโจทย์ที่แนบมา

## ฟังก์ชัน
- Responsive สำหรับมือถือ แท็บเล็ต และเดสก์ท็อป
- Navbar อยู่ด้านบนและมีเมนูมือถือ
- เมนูอาหาร 6 รายการ พร้อมภาพ ชื่อ คำอธิบาย และราคา
- ปุ่มสุ่มเมนู เปลี่ยนชื่อ คำอธิบาย ราคา และรูปของเมนูแนะนำ
- ปุ่มหัวใจบันทึกเมนูโปรดด้วย `localStorage`
- ฟอร์มติดต่อ ตรวจสอบช่องที่จำเป็นและบันทึกข้อความด้วย `localStorage`
- ใช้ Google Fonts (Kanit และ Playfair Display) และ CSS ที่เขียนเอง

## วิธีเปิดใช้งาน
1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ `dark_food_portfolio`
3. เปิด `index.html` ใน Chrome, Edge หรือ Firefox

แนะนำ: ใช้ส่วนขยาย **Live Server** ใน VS Code เพื่อเปิดเว็บผ่าน local server
คลิกขวา `index.html` → **Open with Live Server**

## หมายเหตุ
- รูปภาพดึงจาก Unsplash และฟอนต์ดึงจาก Google Fonts จึงต้องเชื่อมต่ออินเทอร์เน็ตเพื่อแสดงผลครบถ้วน
- ฟอร์มในเวอร์ชันนี้บันทึกข้อมูลในเบราว์เซอร์ของเครื่องผู้ใช้เท่านั้น ไม่ได้ส่งอีเมลหรือบันทึกลงฐานข้อมูลจริง
- ข้อมูลที่บันทึกสามารถดูได้ใน DevTools → Application → Local Storage → origin ของเว็บ โดยใช้คีย์ `noir-table-favorites` และ `noir-table-messages`
- เปลี่ยนอีเมล ชื่อแบรนด์ รูปภาพ และข้อความต่าง ๆ ได้ใน `index.html`; รายการเมนูและข้อมูลสุ่มอยู่ใน `script.js`
